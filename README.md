# AAS — עוזר AI טלפוני ל-IVR2

שרת Node.js שמחבר שלוחת API במערכת IVR2 של ימות המשיח לעוזר AI בעברית.

## מה המערכת עושה

1. המתקשר מקליט שאלה בשלוחת IVR2.
2. ימות המשיח שולחת לשרת את נתיב ההקלטה בפרמטר rapi.
3. השרת מוריד את ההקלטה דרך API של ימות המשיח.
4. ההקלטה מתומללת באמצעות OpenAI.
5. התמליל נשלח למודל שיחה, והתשובה מוחזרת בפורמט read=t-... להקראה במערכת הטלפונית.

השרת כולל גם /health לבדיקת מצב, /admin לדף מידע מוגן, מגבלת גודל להקלטות, בדיקת מפתח גישה, ולוגים שאינם מדפיסים תוכן שיחות או סודות.

## פריסה

המאגר מוכן ל-Render באמצעות render.yaml. חבר את המאגר לשירות Web Service ב-Render, בחר Blueprint או Node, והגדר את משתני הסביבה המפורטים בקובץ .env.example.

חובה להגדיר:
- OPENAI_API_KEY — מפתח API של OpenAI.
- YEMOT_TOKEN — טוקן ימות המשיח בפורמט מספר מערכת:סיסמת API.
- ACCESS_KEY — מפתח אקראי ארוך שיוודא שרק שלוחת IVR המורשית פונה לשרת.
- ADMIN_PASSWORD — סיסמה לפאנל /admin.

השרת אינו מכיל מפתחות אמיתיים. אין להכניס אותם ל-GitHub.

## חיבור שלוחת IVR2

קובץ docs/IVR2-SETUP.ini מכיל דוגמת הגדרות שמכוונת לכתובת Render שסיפקת: https://zygy-voice-ai-zoo8.onrender.com/run_transcription. החלף את YOUR_ACCESS_KEY במפתח ACCESS_KEY שהגדרת ב-Render, ואת נתיב ההקלטות לפי השלוחה שלך.

כדי לשמור הקשר בין שאלות באותה שיחה, הפעל api_call_id_send=yes. השרת מקבל מזהי שיחה בכמה שמות פרמטרים נפוצים. אם המערכת שלך שולחת מזהה בשם אחר, יש להוסיף אותו ל-sessionIdFromParams ב-src/server.js.

הקלטות נשמרות בשלוחה שהגדרת ב-api_000. השרת מוריד אותן בעזרת YEMOT_TOKEN ששמור במשתני הסביבה של Render.

## נקודות קצה

- GET / — דף סטטוס בסיסי.
- GET /health — JSON עם מצב השירות ונוכחות משתני הסביבה, ללא חשיפת ערכים.
- GET או POST /run_transcription — נקודת החיבור ל-IVR2.
- GET או POST /api/ivr — כינוי נוסף לנקודת החיבור.
- GET /admin — פאנל מידע מוגן בסיסמה.

## פיתוח ובדיקות

גרסת Node הנדרשת: 22 ומעלה.

פקודות:
- npm install
- npm test
- npm start

## מגבלות חשובות

היסטוריית השיחה נשמרת בזיכרון של תהליך Node בלבד ומתאפסת כאשר Render מפעיל מחדש את השירות. כדי לשמור שיחות לאורך זמן או בין כמה מופעי שרת יש להוסיף Redis או מסד נתונים חיצוני. אין כאן הקלטת שיחות או ארכיון תמלולים.

החזרת תשובה קולית מתבצעת באמצעות הוראת read=t- של ימות המשיח. נדרש לבצע שיחת בדיקה אמיתית אחרי ההתקנה ולוודא שהגדרות שלוחת API תואמות למבנה ההקלטה בחשבון שלך.
